# Юный астронавт: База — версия на Unreal Engine 5 (C++)

Это та же игра, что и веб-версия: те же горы и кратеры (рельеф считается той же формулой), та же база
с каютами, кухней, тренажёрами, медотсеком, постом связи, теплицей и лабораторией, тот же луноход,
три члена экипажа ходят по тем же маршрутам, и те же настоящие солнечные бури из архива NOAA/NASA.
Вся логика написана на C++, модели взяты из Blender (папка `Models`).

> Честно: я не мог собрать проект у себя (на сервере нет Unreal). Код написан под UE 5.4 и проверен
> только чтением. Если при сборке появятся ошибки, пришли текст из окна Output, я их исправлю.

## Что нужно установить (Windows)

1. **Epic Games Launcher → Unreal Engine 5.4** (подойдёт и 5.3–5.5: тогда в файле
   `LunarOutpost.uproject` поменяй `"EngineAssociation": "5.4"` на свою версию).
2. **Visual Studio 2022** (бесплатная Community) с набором **«Разработка игр на C++»**
   (Game development with C++). В нём уже есть всё нужное для Unreal.

## Как открыть

1. Скачай репозиторий и открой папку `unreal/LunarOutpost`.
2. Нажми правой кнопкой на `LunarOutpost.uproject` → **Generate Visual Studio project files**.
3. Дважды щёлкни `LunarOutpost.uproject`. Unreal спросит «модули устарели, собрать?» → **Да**.
   Первая сборка идёт 2–10 минут. (Если не собирается: открой `LunarOutpost.sln` в Visual Studio,
   выбери **Development Editor** и нажми **Build** — там видны ошибки.)
4. **Один раз импортируй модели:** в редакторе меню **Tools → Execute Python Script…** и выбери
   `Scripts/import_models.py`. Скрипт загрузит 41 модель из `Models`, таблички из `Textures`
   и создаст материалы в `Content/Outpost`. Подожди, пока в Output Log появится `done`.
5. Нажми **Play** (зелёный треугольник). Карту выбирать не нужно: база строится кодом при старте.

## Управление

| Клавиша | Что делает |
|---|---|
| W A S D | идти (в луноходе: газ, тормоз, руль) |
| Мышь | смотреть |
| Shift | бежать / ехать быстрее |
| Пробел | прыжок (в луноходе: тормоз) |
| E | действие: станция, разговор с экипажем, сесть в луноход / выйти |
| 1, 2, 3 | выбрать задание на станции |
| V | вид от первого / третьего лица |
| L | русский / English |
| F2 | переключить Луну и Марс |
| Enter | начать заново после конца миссии |

Снаружи сила тяжести настоящая: Луна 1,62 м/с², Марс 3,71 м/с². Внутри базы прыжок как на Земле
(это упрощение игры, об этом говорит подсказка). Кислород скафандра снаружи кончается примерно
за 2,5 минуты, внутри базы скафандр заправляется сам.

## Как устроен код (`Source/LunarOutpost`)

| Файл | Что внутри |
|---|---|
| `OutpostCommon` | перевод координат из веб-версии, тот же генератор рельефа (mulberry32, fbm, кратеры, хребты), загрузка моделей |
| `OutpostWorld` | строит всё: рельеф 900×900 м, базу, коридоры, теплицу, лабораторию, карьер, панели, антенну, звёзды, Землю, станции |
| `AstronautCharacter` | игрок: ходьба, прыжки, камеры, клавиша E |
| `RoverPawn` | луноход: та же физика, что в веб-версии (склоны, прыжки на гребнях, повороты колёс) |
| `CrewNPC` | Аня, Тимур и Лина ходят по графу маршрутов веб-версии, работают и поворачиваются к тебе |
| `OutpostGameMode` | 20 дней миссии: энергия, кислород, вода, еда, здоровье, доза, наука; цифры NASA (BVAD, МКС) |
| `OutpostHUD` | панель ресурсов, подсказки, окна станций (рисуется Canvas, шрифт Roboto с кириллицей) |
| `FlareData.inl` | настоящие солнечные вспышки и протонные бури (архив NOAA SWPC / NASA DONKI, не «живые» данные) |
| `OutpostParts.inl` | где стоит каждая деталь моделей (сгенерировано из Blender) |

Модели можно перевыгрузить из Blender скриптом `blender/export_fbx.py` в корне репозитория.

## Чем отличается от веб-версии

Пока это основа, а не полная копия. Мир, база, экипаж, луноход и главные ресурсы уже есть.
Модель дня упрощена: нет экрана «Энергия» с ползунками, режима «Кадет/Инженер», пылевых бурь Марса,
грузовых кораблей и экрана «Наука для жюри». Их можно добавить следующим шагом.
